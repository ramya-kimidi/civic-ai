## 📖 Overview

Smart Civic AI is an intelligent smart-city platform designed to improve transportation, public safety, emergency response, disaster management, infrastructure management, and citizen services.

Using location-based services, emergency alerts, guardian tracking, safe spot identification, transportation services, disaster information, and centralized administration dashboards, Smart Civic AI helps citizens quickly access important services while enabling authorities to monitor and respond to civic and emergency situations.

The platform brings multiple essential city services into a single digital system to create safer, smarter, and more connected urban communities.

---

# 🎯 Problem Statement

Urban communities often face challenges such as:

* Delayed emergency response
* Road accidents
* Public safety concerns
* Transportation difficulties
* Poor emergency communication
* Disaster management challenges
* Difficulty finding nearby safe locations
* Limited communication between citizens and authorities
* Lack of centralized civic services

These issues lead to:

* Increased emergency response time
* Reduced citizen safety
* Traffic and transportation difficulties
* Poor emergency coordination
* Difficulty accessing important civic information
* Communication gaps between citizens and authorities

---

# 💡 Solution

Smart Civic AI provides a centralized digital platform where citizens can access multiple smart-city services.

The platform allows users to:

* Send SOS and emergency alerts
* Access accident assistance
* Share their current location
* Enable guardian tracking
* Find nearby safe locations
* Access transportation services
* Receive disaster information
* Manage their profile
* Access civic services

The system also provides dedicated dashboards for city administrators and emergency administrators to monitor and manage civic activities.

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/ramya-kimidi/civic-ai.git
```

Go into Project

```bash
cd civic-ai
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run Application

```bash
python main.py
```

Or

```bash
flask --app main run
```

Open in browser:

```text
http://127.0.0.1:5000
```
